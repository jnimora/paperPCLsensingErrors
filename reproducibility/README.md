# Reproducibility package

This directory contains the computational artifact associated with the paper.

## Stable public layers

- `src/` — primary Julia modules.
- `notebooks/` — current v4 notebook.
- `data/raw/` — immutable experiment outputs.
- `data/processed/` — canonical processed tables.
- `data/supporting/` — representative and diagnostic outputs.
- `data/checks/` — experiment and release validations.
- `figures/manuscript/` — canonical manuscript PDFs.
- `figures/source/` — selected figure-source provenance.
- `provenance/` — environment, import, curation, and hash records.

## Interpretation

The numerical PCLI results provide evidence in the analytically unresolved
intermediate threshold regime; they are not a proof of global indexability.
The Lagrangian benchmark in the policy datasets is explicitly conditional.
